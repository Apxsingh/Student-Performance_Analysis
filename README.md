# Student Performance Data Analysis Using Python

## 📌 Project Overview

This project focuses on **Data Preprocessing and Visualization** using Python libraries like **NumPy, Pandas, and Matplotlib**.

The project analyzes student performance data including:
- Marks
- Attendance
- Study Hours

The dataset is cleaned, analyzed, and visualized using different charts and graphs.

---

# 🚀 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

---

# 📂 Dataset Features

The dataset contains the following columns:

| Column Name | Description |
|-------------|-------------|
| Name | Student Name |
| Math | Math Marks |
| Science | Science Marks |
| English | English Marks |
| Attendance | Attendance Percentage |
| StudyHours | Daily Study Hours |
